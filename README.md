# Image Tampering Detection using AI

A Python project that checks whether an image has been digitally manipulated. It combines classic image forensics (OpenCV), a machine learning classifier (scikit-learn), and a Streamlit web app for uploading and analyzing images.

## What it does

**1. Forensic analysis** (`analyze_single_image.py`)
Runs five detection techniques on an image and combines them into an overall tampering confidence score (0 to 1) with a Low / Medium / High severity rating:

| Technique | What it looks for |
|---|---|
| Copy-move detection | Regions duplicated within the same image (block correlation) |
| Noise analysis | Areas whose noise pattern differs from the rest of the image |
| JPEG artifact analysis | Compression inconsistencies, using the Discrete Cosine Transform (DCT) |
| Lighting consistency | Unnatural lighting variations, using the LAB color space |
| Edge artifacts | Suspicious edges left behind by splicing (Canny edge detection) |

Results are printed to the console and saved as a JSON report.

**2. Machine learning classifier** (`ml_tampering_detector.py`)
Extracts 22 features from each image (noise, compression, lighting, edges, color, texture, gradients and frequency energy) and trains Random Forest and SVM classifiers to label images as original or tampered. The training set contains 50 original and 50 tampered images (`celebrity_dataset/`), split 80/20 for training and testing. Trained models are saved in `trained_models/`.

**3. Streamlit web app** (`streamlit_app.py`)
Upload an image in the browser and get a quality-based assessment built on blur, sharpness, noise level, compression quality, resolution and color metrics, with charts and a downloadable report.

## Tech stack

Python, OpenCV, NumPy, SciPy, scikit-learn, scikit-image, Streamlit, Plotly, Matplotlib

## Getting started

```bash
pip install -r requirements.txt

# Web app
streamlit run streamlit_app.py

# Forensic analysis of one image
python analyze_single_image.py sample_images/spliced_tampered.jpg

# Train and evaluate the ML classifiers
python ml_tampering_detector.py

# Generate sample tampered images (copy-move, splicing, noise, lighting)
python generate_test_images.py
```

## Project structure

```
analyze_single_image.py    Five-technique forensic analysis of a single image
image_tampering_detector.py Batch forensic analysis of all images in a folder
ml_tampering_detector.py   Feature extraction and Random Forest / SVM training
quality_based_detector.py  Quality metrics used by the web app
streamlit_app.py           Streamlit web interface
generate_test_images.py    Creates sample tampered images for testing
sample_images/             Example authentic and tampered images
celebrity_dataset/         Labeled dataset used to train the classifiers
dataset/                   Additional authentic / tampered image set
trained_models/            Saved Random Forest, SVM and scaler files
```

## Limitations

- The classifiers were trained on a small dataset (100 images), and most tampered images were generated by script, so the test results do not reflect real-world accuracy.
- The forensic scores are heuristics: a heavily compressed authentic photo can still receive a medium tampering score.
- A larger, standard benchmark dataset (such as CASIA) would be the next step for a reliable evaluation.
